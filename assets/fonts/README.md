# Hubot Sans

`hubot-sans-latin-variable.woff2` is an unmodified, locally served Latin subset
from Google's official font distribution. No font requests are made to Google
when the website loads.

- Typeface: Hubot Sans, by the Hubot Sans Project Authors (GitHub and Degarism).
- Upstream: https://github.com/github/hubot-sans
- Downloaded: 2026-09-12.
- Distribution: https://fonts.googleapis.com/css2?family=Hubot+Sans:wght@400..900&display=swap
- Exact font: https://fonts.gstatic.com/s/hubotsans/v5/pe0-MIiULYxOvxVLbVwhONyy6zb7yFM9V5G3ibfb-Vo.woff2
- Size: 48,284 bytes.
- SHA-256: `bf14f3d03f7e62cf5039f85fc2f0bf4a8022b679ba5ca6f876fec0d73b175f66`.
- License: SIL Open Font License 1.1, reproduced without modification in `OFL.txt`.
- Exact license source: https://raw.githubusercontent.com/google/fonts/0b58fb370093f9a9f4ff785d94405710b79de67c/ofl/hubotsans/OFL.txt

The WOFF2 header and decompressed `fvar` table were inspected. The binary has
one variable axis, `wght`, spanning 200–900. It uses upright, normal-width
letterforms. The site may declare the full weight range; the requested
400–900 range is included. No conversion or local subsetting was performed.

Google Fonts declares the Latin subset's coverage as:

```text
U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA,
U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122,
U+2191, U+2193, U+2212, U+2215, U+FEFF, U+FFFD
```

Use a system-font fallback for characters outside this subset. This website
font does not replace the extension's fonts or change its localization support.
