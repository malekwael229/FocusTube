FocusTube / Facebook

Facebook distraction control

Block Facebook Reels without blocking Facebook.

FocusTube can intercept Reels paths and separately hide selected Facebook surfaces such as Reels navigation, Stories and people suggestions.

Add to ChromeFirefoxEdge

What FocusTube changes

Target the distracting surface.

Reels paths
Strict and Warn can intercept supported Reels routes.
Reels navigation
The Reels entry point can be hidden from supported navigation areas.
Stories
Stories can be hidden independently of route blocking.
People suggestions
People You Might Know suggestions can be hidden as a separate visual control.

What stays available

Keep the useful part of Facebook.

Other Facebook pages remain available unless they are part of a specific FocusTube rule. The extension is designed around selective distraction removal rather than a full Facebook block.

Facebook frequently changes its DOM and localized labels. FocusTube uses targeted rules, but upstream UI changes can require maintenance.

Blocking modes

Choose the amount of friction.

Strict blocks the targeted surface immediately. Warn shows an interstitial first. Passive keeps browsing normal while visual hiding controls can still remove selected UI.

Settings, timer state and local estimates remain in browser-local extension storage. FocusTube does not use analytics, tracking, accounts or a project-controlled backend.
