FocusTube / Instagram Reels

Instagram Reels blocker

Open Instagram without being pulled into Reels.

FocusTube recognizes /reels/, /reel/, and /explore/ paths. It can also hide detected Reels navigation and Stories surfaces while leaving other Instagram routes outside the redirect boundary.

Install FocusTubeBack to overview

What changes

Recognized Reels and Explore paths

Strict Mode redirects recognized Reels and Explore paths to the Instagram home route. Warn Mode presents a warning first. Visual hiding can remove Reels navigation and, when enabled and detected, cover the Stories shelf.

Recognized

  • /reels/ and /reel/
  • /explore/ paths
  • Detected Reels navigation and Stories surfaces

Outside this redirect

  • Direct Messages
  • Profiles and notifications
  • Other routes not identified as blockable

Modes

Keep the choice explicit

  • StrictRedirects recognized Reels and Explore paths.
  • WarnShows a warning before entering, with a scoped allow action.
  • PassiveLeaves direct access available while optional visual hiding removes selected entry points.

Privacy boundary

FocusTube runs in the browser, stores settings and statistics locally, and contains no analytics or telemetry. It does not add a remote backend or change Instagram content outside its recognized boundaries. See the security policy.
