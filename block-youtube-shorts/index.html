FocusTube / YouTube Shorts

YouTube Shorts blocker

Use YouTube without the Shorts loop.

FocusTube recognizes YouTube’s /shorts/ routes and selected Shorts entry points. It is designed to leave ordinary video pages, search, subscriptions, playlists, and other useful routes available.

Install FocusTubeBack to overview

What changes

Shorts routes and selected entry points

In Strict Mode, a URL containing /shorts/ is redirected to the YouTube home route. During focus, the same route is blocked. Visual hiding can also remove Shorts navigation links, shelves, chips, tabs, and the English “Most relevant” shelf on Subscriptions when those elements are detected.

Recognized

  • /shorts/ direct links
  • Shorts navigation links
  • Detected Shorts shelves and tabs

Left available

  • Long-form watch pages
  • Search and subscriptions
  • Playlists and ordinary navigation

Modes

Choose how YouTube is handled

  • StrictRedirects recognized Shorts routes.
  • WarnShows a warning before entering a recognized Shorts route, with a scoped allow action.
  • PassiveLeaves direct routes available while visual hiding can remove selected Shorts entry points.

Local and open source

Settings, timer state, and simple blocked-count statistics stay in browser-local storage. FocusTube contains no analytics or telemetry endpoints. Read the architecture and security policy.
