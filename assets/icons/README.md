# Website icon sources

Chrome, Firefox Browser and Edge icons: Font Awesome Free 7.3.1 by Fonticons, Inc., from https://github.com/FortAwesome/Font-Awesome/tree/7.x/svgs/brands (CC BY 4.0; see LICENSE.txt). The fill color is adapted to the website foreground. No JavaScript or font icon package is used.

Instagram's SVG is reused from FocusTube's popup.html; its fill color is adapted to the website foreground. Other platform marks and the GitHub mark are reused inline from popup.html. FocusTube's own logo remains in the existing icons/ directory.
