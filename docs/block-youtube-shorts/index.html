FocusTube / YouTube

YouTube distraction control

Block YouTube Shorts without blocking YouTube.

Keep regular videos, search and subscriptions available while FocusTube blocks or hides the Shorts surfaces that pull you into short-form scrolling.

Add to ChromeFirefoxEdge

What FocusTube changes

Target the distracting surface.

Shorts routes
Strict and Warn can intercept supported Shorts URLs.
Shorts navigation
The Shorts entry point can be hidden from YouTube navigation.
Shorts shelves
Shorts shelves can be hidden from supported YouTube pages.
Subscriptions clutter
FocusTube can hide the English “Most relevant” shelf on the Subscriptions page.

What stays available

Keep the useful part of YouTube.

Regular videos, search, channels, subscriptions and other normal YouTube pages remain available unless a separate FocusTube control targets them.

YouTube changes its interface regularly. FocusTube may occasionally need selector updates when YouTube changes markup or labels.

Blocking modes

Choose the amount of friction.

Strict blocks the targeted surface immediately. Warn shows an interstitial first. Passive keeps browsing normal while visual hiding controls can still remove selected UI.

Settings, timer state and local estimates remain in browser-local extension storage. FocusTube does not use analytics, tracking, accounts or a project-controlled backend.
