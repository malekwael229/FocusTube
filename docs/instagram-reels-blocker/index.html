FocusTube / Instagram

Instagram distraction control

Block Instagram Reels without losing the rest of Instagram.

FocusTube can block Reels and Explore routes, then separately hide Reels navigation and Stories so the parts you still use stay available.

Add to ChromeFirefoxEdge

What FocusTube changes

Target the distracting surface.

Reels routes
Strict and Warn can intercept supported Reels URLs.
Explore
Explore routes can be treated as distracting surfaces.
Reels button
The Reels navigation entry can be hidden.
Stories
The Stories tray can be hidden separately from route blocking.

What stays available

Keep the useful part of Instagram.

Messages, profiles and other Instagram pages can remain available while you remove the short-form surfaces you do not want.

Instagram is a dynamic single-page application, so FocusTube watches navigation and DOM updates to keep the selected controls applied.

Blocking modes

Choose the amount of friction.

Strict blocks the targeted surface immediately. Warn shows an interstitial first. Passive keeps browsing normal while visual hiding controls can still remove selected UI.

Settings, timer state and local estimates remain in browser-local extension storage. FocusTube does not use analytics, tracking, accounts or a project-controlled backend.
