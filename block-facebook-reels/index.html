FocusTube / Facebook Reels

Facebook Reels blocker

Keep Facebook useful without the Reels detour.

FocusTube recognizes /reel, /reels, and their nested routes. Optional visual hiding can cover detected Reels navigation and the Stories shelf while non-Reels routes remain outside the route redirect.

Install FocusTubeBack to overview

What changes

Reels routes and selected surfaces

Strict Mode redirects recognized Reels routes. Warn Mode presents a warning first. When visual hiding is enabled, the adapter can cover detected Reels navigation and Stories without applying a broad page-wide block.

Recognized

  • /reel and /reels
  • Detected Reels navigation
  • Detected Stories shelf

Kept outside the route redirect

  • Non-Reels Facebook routes
  • Groups and community pages where detected
  • Messenger and notifications where detected

Modes

Use redirects, warnings, or hiding

  • StrictRedirects recognized Reels routes.
  • WarnShows a warning before entry with a scoped allow action.
  • PassiveLeaves routes available while optional visual hiding can remove selected entry points.

Privacy by design

FocusTube keeps preferences, timer state, and simple statistics in local browser storage. It includes no analytics or telemetry and no project-controlled backend. Read the security policy.
